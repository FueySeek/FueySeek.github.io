Update Log

All changes to this project are recorded here.

  • v26.10.29.0
    Date Format Fix & Sub-page
    Added
    • Added a sub-page inside the embed, loaded by the embed itself using the same rules and width.
    • The sub-page updates its height and language together with the parent embed.
    Changed
    • Dates are no longer hardcoded in the markup; they are stored as data and formatted per language.
    • Chinese dates now display as YYYY/MM/DD; English dates display as DD/MM/YYYY.
    Fixed
    • Date format no longer stays fixed when switching languages.
    • Sub-page now follows language changes from the embed.
  • v26.10.13.1
    Left-handed Mode & Interaction Fixes
    Added
    • Left-handed mode: settings panel now slides out from the left with a smooth transition.
    • Settings panel can now be closed by dragging it back to the edge; dragging about one third of the panel width closes it.
    • Security warning inside the embed panel is now forwarded to the parent page, so it uses the same UI and language as the main page.
    Changed
    • Left-handed mode: settings panel now keeps its rounded corners and its 16px gap from the browser edge.
    • Left-handed mode: toggle now plays the panel close animation before mirroring the layout.
    • Task lock now prevents two drag gestures from running at the same time; the first one wins.
    • Page scroll is locked while a drag gesture or the settings panel is active.
    Fixed
    • Left-handed mode: settings panel no longer drifts when dragged to close.
    • Download page and About page now mirror correctly in left-handed mode.
    • Missing left-handed translations added to the language file.
  • v26.10.13.0
    Search Bar & Multi-language Improvements
    Added
    • Download page: added a search bar with a fully rounded design.
    • Search matches both Chinese and English names, regardless of the current language.
    • Embed panel: grows with its content, no more fixed height.
    • Embed panel: real-time height sync when the content changes.
    • Embed panel: cache refresh so the latest content is always loaded.
    Changed
    • Default language changed to English.
    • Top navigation bar is now fully rounded.
    • Search results now display only in the current language, no mixed output.
    Fixed
    • Default language mismatch on the Download and About pages.
    • Language switch not reflected correctly in the settings panel.
    • Embed panel not visible on mobile and server deployments.
  • v26.10.12.0
    Embed Panel
    Added
    • Added an expandable embed area below the homepage hero.
    • Added a scroll-down circular button with a glow effect.
    • Embedded content is loaded separately from the main page.
    Changed
    • Homepage layout adjusted so the embed area sits below the first screen.
  • v26.10.11.0
    Settings & Theme
    Added
    • Added a draggable segmented control in the settings panel.
    • Added light / dark theme toggle with a liquid transition.
    • Added English / Chinese language toggle.
    • Added a reset settings button with a confirmation dialog.
    Changed
    • Overall UI changed to a glassmorphism style.
    • Buttons and cards changed to fully rounded corners.
  • v26.10.10.0
    First Release
    Added
    • Initial homepage with hero text and person image.
    • Download page.
    • About page with a configurable link list.
    • Custom cursor and custom font.
